# ADR-014 — React + TypeScript for Dashboard

## Status
Accepted

## Decision
Use React and TypeScript for the FrontWatch web application.

## Rationale
The dashboard is a dense interactive engineering tool requiring mature support for data-heavy interfaces, charts, tables, timelines, routing, complex state, and accessibility.

## Consequence
The dashboard architecture should be feature-oriented rather than organized only by generic UI components. See `06-engineering-specs/frontend/`.
