# Workflow — Alert Investigation

**Goal:** turn an alert into a useful investigation, not just something to acknowledge.

**Flow:** Alert → why did it trigger? → affected application/environment → metric trend → issue(s) → release → sessions → network/performance evidence → resolution.

**Alert detail shows:** trigger condition, actual value, threshold, evaluation window, first-triggered time, current state, related issues, related release.

**States:** Triggered → Acknowledged → Recovered → Resolved.
