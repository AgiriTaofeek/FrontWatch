# Workflow — Session Investigation

**Goal:** reconstruct what happened during an affected customer session.

**Flow:** Issue → affected session → session overview → timeline (navigation, interaction, network, performance, errors) → failure point → related issue.

**Session view must show:** session identifier, start/end time, route history, browser/device, relevant errors, network failures, performance events.

**Privacy:** sensitive user information must be hidden or redacted according to configured policy — this is not optional per-session.
