# Workflow — Application Setup

**Goal:** register an application and prepare an environment for monitoring.

**Flow:** Applications → create application → application details → create environment → framework selection → SDK setup instructions → connection verification.

**Required information:** application name, framework, environment, monitoring configuration.

**Framework selector must distinguish:** React, Next.js, React Router, Remix, TanStack Start, Vue, Nuxt, Svelte, SvelteKit, Solid, SolidStart — and, where relevant, rendering mode (SPA, SSR, SSG, Hybrid).
