# E12 — Application Health

## US-12.01 — View Application Health
**Priority:** P0

**As a** software engineer, **I want** an application health overview, **so that** I can quickly determine whether production is healthy.

**Acceptance criteria:** the dashboard shows current error health · performance health is represented · network health is represented · release health is represented · the time window is clear.

## US-12.02 — View Health Trends
**Priority:** P0

**As a** CTO or engineer, **I want** health trends over time, **so that** I can identify degradation.

**Acceptance criteria:** historical health can be viewed · major changes are visible · health can be filtered by environment.
