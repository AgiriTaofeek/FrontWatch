# Deployment Models

## Profile A — Local

Docker Compose for development, testing, and demos.

## Profile B — Small Self-Hosted

A single VM or small Kubernetes deployment for pilots and smaller teams.

## Profile C — Production

Kubernetes with horizontally scalable stateless workloads.

## Profile D — Enterprise Banking

May include:

- private networks
- internal load balancers
- enterprise identity
- customer certificates
- private registries
- high availability
- strict network policies
- centralized logging
- backup/DR
- customer-managed storage

All profiles use the same logical product architecture; topology and capacity differ.
