# Visual Regression

## Scope

Prioritize:

```text
design-system components
health dashboard
issue investigation
session timeline
charts
tables
alert builder
```

## Viewports

Test representative:

```text
desktop
tablet
```

Mobile behavior should be intentionally defined even if desktop is the primary experience.

## States

Capture:

```text
loading
empty
success
error
degraded
```

## Review

Visual diffs require intentional review.

Do not blindly update snapshots.
