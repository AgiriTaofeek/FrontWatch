# Accessibility Testing

## Automated

Run accessibility checks against critical screens.

## Manual

Test:

- keyboard-only navigation
- focus management
- screen reader labels
- reduced motion
- high zoom
- color-independent status

## Critical Screens

```text
login
dashboard
issue explorer
issue investigation
session investigation
alert builder
settings
```

## Regression

Accessibility checks should be part of release quality gates for core workflows.
