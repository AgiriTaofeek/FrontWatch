# Acceptance Criteria

A feature is not complete merely because its implementation exists.

## Feature Acceptance

Every user story should define:

```text
Given
When
Then
```

## Example

```text
Given an application with production errors
When an engineer opens the issue explorer
Then the current production issues are displayed
And the engineer can filter by release
And selecting an issue opens its investigation
```

## Non-Functional Acceptance

Where applicable include:

```text
security
performance
accessibility
observability
failure behavior
auditability
```

## Evidence

Acceptance should link to:

- automated tests
- screenshots where useful
- test runs
- performance results
- security results
