# Task Conventions

## IDs

```text
EPIC: E01
FEATURE: E01-F01
STORY: E01-F01-S01
TASK: E01-F01-S01-T01
```

## Priority

```text
P0 release blocker
P1 MVP critical
P2 important
P3 post-MVP
```

Every task needs a clear outcome, dependencies, acceptance criteria, tests, and security considerations where relevant.
