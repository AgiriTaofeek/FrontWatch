# Engineering Risk Register

## R01 — Telemetry volume exceeds design
Load tests, quotas, sampling, backpressure, scaling.

## R02 — Query performance poor
Profiling, aggregation, indexes, limits.

## R03 — SDK overhead
Bundle/CPU/memory budgets and asynchronous transport.

## R04 — Tenant isolation failure
Defense in depth and automated isolation suite.

## R05 — Self-hosting too complex
Deployment profiles, Helm, preflight, documentation.

## R06 — MVP scope expands
Strict MVP definition and release gates.
