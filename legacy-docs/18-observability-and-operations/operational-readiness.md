# Operational Readiness Review

Before production readiness, verify:

## Reliability

```text
SLOs defined
alerts defined
runbooks exist
on-call exists
```

## Data

```text
backup tested
restore tested
retention configured
freshness monitored
```

## Security

```text
access controls
audit logs
security scanning
incident response
```

## Deployment

```text
CI/CD
rollback
migration strategy
upgrade path
```

## Capacity

```text
load tested
storage sized
growth monitored
```

## Ownership

Every critical component has an operational owner.
