# Postmortems

## Purpose

Learn from incidents without turning the process into blame.

## Required Sections

```text
Summary
Impact
Timeline
Detection
Root cause
Contributing factors
What went well
What went poorly
Corrective actions
Owners
Due dates
```

## Detection Review

Ask:

```text
Could FrontWatch have detected this earlier?
```

## Monitoring Review

Ask:

```text
Which signal was missing?
Which alert was noisy?
Which dashboard was insufficient?
```

## Follow-Up

Actions should become tracked engineering work rather than remaining in a document.
