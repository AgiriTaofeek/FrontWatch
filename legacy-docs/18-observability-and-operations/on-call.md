# On-Call

## Responsibilities

On-call engineers should be able to:

- inspect platform health
- identify affected component
- follow runbook
- mitigate
- escalate
- document incident

## Rotation

Define:

```text
primary
secondary
escalation
```

according to team size.

## Handoff

Handoffs should include:

```text
active incidents
degraded systems
planned deployments
capacity concerns
security concerns
```

## On-Call Metrics

Track:

```text
pages
acknowledgement time
MTTR
false positives
repeat incidents
```

## Principle

The system should page people only when human intervention is reasonably required.
