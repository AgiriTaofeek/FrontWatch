# Operational KPIs

## Reliability

```text
availability
SLO attainment
error budget consumption
incident count
```

## Performance

```text
API latency
ingestion latency
query latency
processing latency
```

## Data

```text
event throughput
rejection rate
freshness
processing success
```

## Operations

```text
MTTD
MTTA
MTTR
deployment frequency
change failure rate
```

## Capacity

```text
storage growth
CPU utilization
memory utilization
queue capacity
```

KPIs should drive decisions, not become vanity metrics.
