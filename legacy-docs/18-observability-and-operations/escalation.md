# Escalation

## Levels

Example:

```text
L1 — On-call engineer
L2 — Platform/backend specialist
L3 — Security/infrastructure lead
L4 — Engineering leadership
```

Actual roles depend on team size.

## Escalation Triggers

Examples:

```text
SLO breach
security incident
data integrity concern
prolonged ingestion outage
storage exhaustion
customer-wide impact
```

## Time-Based Escalation

Critical incidents should have explicit response deadlines.

## Ownership

Every active incident has one clearly identified owner.
