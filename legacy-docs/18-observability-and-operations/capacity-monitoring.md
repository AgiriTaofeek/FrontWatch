# Capacity Monitoring

## Monitor

```text
CPU
memory
disk
database connections
ClickHouse storage
queue retention
ingestion throughput
query concurrency
```

## Forecasting

Track trends rather than only current utilization.

Examples:

```text
storage days remaining
queue capacity remaining
expected monthly growth
```

## Thresholds

Use warning and critical thresholds with sufficient lead time.

## Capacity Reviews

Regularly review:

```text
growth
customer count
events/day
retention
query load
```

## Goal

Capacity problems should be identified before they become incidents.
