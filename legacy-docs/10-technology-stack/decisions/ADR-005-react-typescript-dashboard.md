# ADR-005 — React + TypeScript for Dashboard

## Status

Accepted

## Decision

Use React and TypeScript for the FrontWatch web application.

## Rationale

The dashboard is a dense interactive engineering tool requiring mature support for:

- data-heavy interfaces
- charts
- tables
- timelines
- routing
- complex state
- accessibility

## Consequence

The dashboard architecture should be feature-oriented rather than organized only by generic UI components.
