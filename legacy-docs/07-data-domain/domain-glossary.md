# FrontWatch — Domain Glossary

## Organization
The customer/company boundary in FrontWatch.

## User
A human who uses the FrontWatch platform.

## Membership
A user's relationship with an organization, including role and access.

## Application
A frontend product being monitored.

## Environment
A deployment context such as production, staging, or development.

## Project
The SDK/telemetry identity used to associate incoming data with an application/environment.

## Release
A version of application code.

## Deployment
The act of putting a release into an environment.

## Event
A raw observation captured from a monitored application.

## Issue
A logical grouping of related error occurrences.

## Occurrence
One observed instance belonging to an issue.

## Session
A browser/application activity boundary used for investigation.

## Breadcrumb
A contextual event that helps reconstruct a session.

## Network Request
Observable browser-side communication with a resource or API.

## Performance Sample
A captured measurement of frontend performance.

## Health
A derived representation of application operating condition.

## Alert Rule
A configured condition that can trigger a notification.

## Alert
An evaluated occurrence of an alert rule.

## Correlation
A relationship between observations that may help explain behavior.

## Telemetry
The overall stream of observations produced by monitored applications.
