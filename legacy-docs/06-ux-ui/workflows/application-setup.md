# Workflow — Application Setup

## Goal

Register an application and prepare an environment for monitoring.

## Flow

```text
Applications
    ↓
Create application
    ↓
Application details
    ↓
Create environment
    ↓
Framework selection
    ↓
SDK setup instructions
    ↓
Connection verification
```

## Required Information

- Application name
- Framework
- Environment
- Monitoring configuration

## Framework Selection

The framework selector should distinguish:

```text
React
Next.js
React Router
Remix
TanStack Start
Vue
Nuxt
Svelte
SvelteKit
Solid
SolidStart
```

Rendering mode should also be considered where relevant:

```text
SPA
SSR
SSG
Hybrid
```
