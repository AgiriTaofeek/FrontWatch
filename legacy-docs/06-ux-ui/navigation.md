# Navigation

## Primary Navigation

The application should prioritize operational workflows.

```text
Overview
Applications
Explore
Alerts
Settings
```

## Application Navigation

When an application is selected:

```text
Health
Issues
Performance
Network
Sessions
Releases
Alerts
Settings
```

## Investigation Navigation

Investigation pages should support contextual navigation.

Example:

```text
Issue
  ↓
Affected Session
  ↓
Network Request
  ↓
Release
```

The user should be able to move backward without losing the investigation context.

## Global Search

Search should be available from anywhere.

Potential search targets:

- Issue ID
- Error message
- Release
- Route
- Session ID
- User identifier where permitted
- Request
