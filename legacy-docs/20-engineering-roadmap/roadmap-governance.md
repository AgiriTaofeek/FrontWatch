# Roadmap Governance

## Roadmap Inputs

Use evidence from:

```text
customer incidents
pilot feedback
support
product analytics
security findings
performance data
engineering constraints
```

## Prioritization

Evaluate:

```text
customer value
strategic value
risk reduction
revenue opportunity
engineering effort
dependency
```

## Reassessment

Review the roadmap after major releases rather than treating it as immutable.

## Decision Record

For major roadmap changes record:

```text
decision
reason
evidence
impact
date
owner
```
