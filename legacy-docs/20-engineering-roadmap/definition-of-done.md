# Definition of Done

A story is Done when:

```text
implementation complete
tests pass
acceptance criteria pass
security implications addressed
logging/metrics added where needed
documentation updated where needed
code reviewed
CI passes
```

## Production-Critical Work

Also requires:

```text
operational impact assessed
rollback considered
performance considered
```

## No "Almost Done"

A feature hidden behind broken states, missing loading behavior, or missing error handling is not complete.
