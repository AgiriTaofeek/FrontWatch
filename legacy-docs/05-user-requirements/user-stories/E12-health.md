# E12 — Application Health

## US-12.01 — View Application Health
**Priority:** P0

**As a** software engineer,  
**I want** an application health overview,  
**so that** I can quickly determine whether production is healthy.

### Acceptance Criteria
- The dashboard shows current error health.
- Performance health is represented.
- Network health is represented.
- Release health is represented.
- The time window is clear.

## US-12.02 — View Health Trends
**Priority:** P0

**As a** CTO or engineer,  
**I want** health trends over time,  
**so that** I can identify degradation.

### Acceptance Criteria
- Historical health can be viewed.
- Major changes are visible.
- Health can be filtered by environment.
