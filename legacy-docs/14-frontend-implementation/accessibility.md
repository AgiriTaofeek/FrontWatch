# Accessibility

## Requirements

Target WCAG 2.2 AA where practical.

## Keyboard

All major workflows must be keyboard accessible.

## Focus

Focus should remain predictable when:

- dialogs open
- filters change
- navigation occurs
- lists update

## Screen Readers

Controls and status changes need meaningful accessible names.

## Color

Do not rely only on color for:

```text
error
warning
success
severity
```

## Motion

Respect reduced-motion preferences.

## Tables

Complex tables require meaningful headers and row relationships.

## Charts

Provide text alternatives/summaries.

## Errors

Error messages should explain:

```text
what happened
what the user can do
```
