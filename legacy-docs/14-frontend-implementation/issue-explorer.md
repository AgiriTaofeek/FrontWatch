# Issue Explorer

## Purpose

Give engineers a fast list of application problems.

## Table Columns

Potential:

```text
Issue
Status
Events
Affected sessions
First seen
Last seen
Release
Route
```

## Filters

```text
environment
status
release
route
browser
time range
```

## Search

Search by:

```text
issue title
message
fingerprint
```

## Sorting

Common:

```text
last seen
event count
affected sessions
first seen
```

## Virtualization

Large lists should use virtualization when necessary.

## Empty State

Differentiate:

```text
No issues exist
```

from:

```text
Unable to load issues
```

## Investigation

Clicking an issue should preserve relevant filter context where useful.
