# Issue Investigation

## Goal

Answer:

```text
What happened?
Who is affected?
When did it start?
What changed?
How can I reproduce/investigate it?
```

## Page Structure

```text
Issue header
 ↓
Error summary
 ↓
Trend
 ↓
Affected releases
 ↓
Affected routes
 ↓
Affected browsers/devices
 ↓
Occurrences
 ↓
Related sessions
 ↓
Network context
```

## Header

Show:

```text
title
status
first seen
last seen
occurrences
affected sessions
```

## Timeline

Show when the issue changed.

Potential markers:

```text
first seen
deployment
regression
recovery
```

## Evidence

The UI should distinguish:

```text
observed
correlated
inferred
```

Do not present correlation as proven causation.

## Actions

Initial:

```text
resolve
reopen
assign
mute
share
```
