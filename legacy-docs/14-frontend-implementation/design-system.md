# FrontWatch Design System

## Goal

Create a consistent engineering-focused interface.

## Foundations

Define:

```text
typography
spacing
radius
elevation
icons
colors
motion
density
```

## Semantic Status

Use semantic concepts:

```text
success
warning
danger
info
neutral
unknown
```

Do not communicate meaning through color alone.

## Components

Initial primitives:

```text
Button
Input
Select
Tabs
Dialog
Popover
Tooltip
Badge
Alert
Table
Card
Dropdown
Command Menu
Date Range Picker
```

## Data Components

```text
Metric Card
Trend Chart
Issue List
Timeline
Event Detail
Status Indicator
```

## Density

The product is primarily used by engineers during investigations.

Support a compact information-dense mode without becoming visually chaotic.
