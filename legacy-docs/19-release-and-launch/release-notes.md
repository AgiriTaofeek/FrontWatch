# Release Notes

Every release should communicate:

```text
Highlights
New features
Improvements
Bug fixes
Security fixes
Breaking changes
Migration notes
Known issues
```

## Security

Security fixes should clearly state affected versions and recommended action when appropriate.

## Upgrade Guidance

If an upgrade requires:

```text
migration
configuration change
SDK update
infrastructure change
```

make it prominent.

## Tone

Release notes should help operators decide:

```text
Should I upgrade?
What can break?
What do I need to do?
```
