# Beta Strategy

## Purpose

Validate:

```text
product usefulness
deployment experience
telemetry correctness
operational reliability
performance
security assumptions
```

## Pilot Selection

Prefer customers with:

- real frontend applications
- strong engineering teams
- clear monitoring pain
- willingness to provide feedback
- suitable self-hosted infrastructure

## Pilot Scope

Start with one application/environment where possible.

## Success

Measure:

```text
time to install
time to first telemetry
bugs detected before customers
time to investigate incidents
dashboard usage
SDK overhead
deployment reliability
```

## Exit Criteria

Move toward stable when:

```text
critical bugs resolved
deployment repeatable
telemetry trustworthy
security baseline satisfied
support process ready
```
