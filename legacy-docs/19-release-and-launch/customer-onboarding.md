# Customer Onboarding

## Journey

```text
Contract / approval
 ↓
Infrastructure preparation
 ↓
Installation
 ↓
Identity configuration
 ↓
Application registration
 ↓
SDK installation
 ↓
Source maps
 ↓
Privacy configuration
 ↓
Alert configuration
 ↓
Validation
 ↓
Go-live
```

## Time to Value

Track:

```text
installation time
time to first telemetry
time to first detected issue
```

## Onboarding Checklist

Customer team should know:

```text
who administers FrontWatch
who receives alerts
where data is stored
how upgrades happen
how backups work
how support is contacted
```
