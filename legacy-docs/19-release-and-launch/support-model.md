# Support Model

## Support Levels

Potentially:

```text
documentation
standard support
priority support
enterprise support
```

Exact commercial tiers should be defined separately.

## Support Intake

Capture:

```text
version
deployment model
environment
symptoms
logs
request ID
recent changes
```

## Security Issues

Security reports require a dedicated process separate from ordinary product support.

## Escalation

Define when issues move from:

```text
support
→ engineering
→ security
→ infrastructure
```

## Self-Hosted

Support must distinguish:

```text
FrontWatch software problem
vs
customer infrastructure problem
```
