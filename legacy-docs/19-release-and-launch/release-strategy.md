# Release Strategy

## Channels

```text
canary
beta
stable
```

## Canary

Used internally and by highly technical early adopters.

## Beta

Used by selected pilot customers.

## Stable

Production release recommended for general customer use.

## Versioning

Use semantic versioning where practical.

## Release Criteria

A release requires:

```text
quality gates
security review
migration validation
operational readiness
known-risk review
rollback plan
```

## Artifact

Every release must identify:

```text
version
commit
container images
SDK versions
database migration
```
