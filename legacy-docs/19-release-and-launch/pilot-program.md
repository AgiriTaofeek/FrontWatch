# Pilot Program

## Pilot Phases

```text
Technical onboarding
 ↓
Telemetry validation
 ↓
Operational observation
 ↓
Real incident usage
 ↓
Feedback
 ↓
Stabilization
```

## Pilot Checklist

Customer confirms:

```text
installation successful
SDK installed
source maps configured
data visible
privacy rules configured
alerts configured
backup configured
```

## Feedback

Collect structured feedback around:

- installation
- UX
- investigation
- performance
- reliability
- missing capabilities

## Important

Do not treat every feature request as MVP scope.

Separate:

```text
bug
usability issue
missing critical capability
nice-to-have
```
