# MVP Definition

## MVP Objective

The MVP must prove the central FrontWatch value proposition:

> Give engineering teams private, self-hosted visibility into the health, failures, performance, network behavior, sessions, and releases of their frontend applications.

## MVP Users

```text
Software Engineers
DevOps
CTO / Engineering Leadership
```

## MVP Capabilities

### Platform

```text
self-hosted deployment
authentication
organizations/projects
applications/environments
RBAC
```

### SDK

```text
errors
network
performance
navigation
sessions
breadcrumbs
privacy/redaction
release context
```

### Dashboard

```text
health
issues
issue investigation
sessions
performance
network
releases/deployments
```

### Operations

```text
alerts
internal observability
backups
security controls
```

## Explicitly Defer

Advanced capabilities such as sophisticated ML anomaly detection, broad integrations, custom dashboards, and extensive workflow automation can follow after the core investigation loop is proven.
