# FrontWatch

FrontWatch project documentation.

## Structure

- **[`FORMULA.md`](FORMULA.md)** — the reusable, product-agnostic documentation methodology this repo follows. Read this first; it explains *why* `docs/` is shaped the way it is, and it's designed to be copied into future projects.
- **[`preamble.md`](preamble.md)** — the original framing conversation that kicked off product discovery.
- **[`docs/`](docs/)** — the current, lean documentation set, built with `FORMULA.md`. **Start at [`docs/README.md`](docs/README.md)** — it's a navigation hub with reading paths by role/purpose (engineer, product, UX, architecture review, security review...), not just a file listing.
- **[`legacy-docs/`](legacy-docs/)** — the original 406-file, 22-phase documentation set. Kept for reference and traceability, not deleted — real thinking happened there, and `docs/` was distilled from it. Not maintained going forward; treat `docs/` as the source of truth.
